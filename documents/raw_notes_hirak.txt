Models and Infrastructure:
- Claim extraction: Mistral 7B via Ollama (local, no GPU, runs on Apple Silicon via Metal)
- Embeddings: SPECTER2 (allenai/specter2_base), 768-dimensional vectors
- Clustering: HDBSCAN (min_cluster_size=2, min_samples=1, epsilon=0.8)
- NLI: DeBERTa-v3-base-zeroshot-v1, label order read from model config at runtime
- Gap generation: Mistral 7B via Ollama (same instance as claim extraction)
- Sentence tokenization: spaCy en_core_web_sm
- PDF parsing: PyMuPDF (fitz)

Bugs Found and Fixed During Development:
- NLI label order was hardcoded as [contradiction, neutral, entailment] — if model uses different order, ALL predictions silently wrong. Fixed: now reads from model.config.id2label
- PDF parser collapsed ALL whitespace to single space, destroying paragraph breaks. Fixed: preserves \n\n
- Section segmenter matched keywords anywhere in body text (e.g., "introduction" mid-sentence). Fixed: anchored to line starts
- claims/prompts.py had a better prompt but was NEVER imported — claim_extractor.py used worse inline prompt. Fixed: wired it in
- app.py skipped NLI entirely (only main.py ran it). Fixed: both now call same run_pipeline()
- SPECTER2 model name "allenai/specter2" requires PEFT adapter, fails to load. Fixed: use "allenai/specter2_base"
- Ollama calls routed through system proxy, causing connection errors. Fixed: proxies={"http": None}
- ArXiv returns 429 on repeated requests. Fixed: retry with backoff (3s, 6s, 9s, 12s, 15s)
